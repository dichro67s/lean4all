## Conventions

- Use `Mathlib.AlgebraicGeometry.AffineSpace` or `Fin n → k` for affine space $\mathbf{A}^n$ over a field $k$.
- Use `Ideal k` for ideals in the polynomial ring $A = k[x_1, \dots, x_n]$.
- Use `Set (Fin n → k)` for subsets of affine space.
- Define `Z (T : Set (Ideal k))` as the set of common zeros of the ideal generated by $T$, or more commonly `V (I : Ideal k)` for the vanishing set of an ideal $I$.
- Use `IsAlgebraicSet` or a predicate `IsZariskiClosed` to denote algebraic sets (closed sets in the Zariski topology).
- The Zariski topology is defined via `TopologicalSpace` instance on `Fin n → k` where closed sets are algebraic sets.
- Use `I (Y : Set (Fin n → k))` for the ideal of polynomials vanishing on $Y$.
- Assume `k` is a field (`Field k`) unless specified otherwise (e.g., algebraically closed for Nullstellensatz).

## Shared definitions

```lean
import Mathlib

set_option autoImplicit false

namespace SrcHartsAg

/-- The vanishing set $Z(T)$ of a subset $T$ of the polynomial ring $A = k[x_1, \dots, x_n]$. It is the set of points $P \in \mathbf{A}^n$ such that $f(P) = 0$ for all $f \in T$. -/
def vanishingSet {k : Type*} [Field k] {n : Type*} [Fintype n] [DecidableEq n]
    (T : Set (MvPolynomial n k)) : Set (n → k) :=
  { P | ∀ f ∈ T, MvPolynomial.eval P f = 0 }

/-- A subset $Y$ of $\mathbf{A}^n$ is an algebraic set if there exists a subset $T$ of the polynomial ring $A$ such that $Y = Z(T)$. -/
def algebraicSet {k : Type*} [Field k] {n : Type*} [Fintype n] [DecidableEq n]
    (Y : Set (n → k)) : Prop :=
  ∃ T : Set (MvPolynomial n k), Y = vanishingSet T

end SrcHartsAg
```
